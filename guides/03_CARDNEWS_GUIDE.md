# Card News Guide

## 목적

카드뉴스는 블로그 글의 모든 내용을 담는 자료가 아니다. 원문의 핵심 질문과 장면을 시각적으로 전달하는 콘텐츠다.

## 구성 기준

- 한 장에는 하나의 메시지만 담는다.
- 카드별로 제목, 본문, 시각 방향, 강조 문장을 구분한다.
- 원문의 흐름을 유지하되, 시각 콘텐츠에 맞게 압축한다.
- 설명보다 장면, 질문, 대비, 여운을 우선한다.

## 첫 장 이미지 기준

앞으로 카드뉴스 첫 장에는 이미지를 반드시 포함한다. 기존 콘텐츠 중 타이포그래피만으로 제작된 표지도 있으나, 이는 이전 제작 사례일 뿐 새 제작 기준으로 삼지 않는다.

- 첫 장은 본문 주제나 핵심 정서를 암시하는 이미지를 반드시 포함한다.
- 이미지를 넣을 때는 글의 장면이나 주제를 암시하는 배경 이미지로 사용하고, 제목·질문보다 시선을 끌지 않도록 어둡게 처리하거나 투명도를 낮춘다.
- 이미지가 텍스트의 가독성을 해치거나 장식적으로만 남는다면 사용하지 않는다.
- 이미지가 적절하지 않더라도 이미지 없이 진행하지 말고, 추상적 질감·사물·공간·상징 장면 등 대체 이미지를 선정한다.
- 첫 장 제작안에는 `이미지 사용: 예`와 `이미지 역할·출처·텍스트 가독성 처리`를 기록한다.
- 최종 검수에서 첫 장의 이미지 삽입 여부와 함께 표지의 핵심 질문 또는 정서가 한눈에 전달되는지 확인한다.

## 카드 구성 예시

```text
1. 표지: 핵심 질문 또는 정서
2. 장면: 글의 출발점이 되는 경험
3. 질문: 독자에게 남길 물음
4. 사유: 의미의 확장
5. 적용: 삶으로 돌아가는 문장
```

## 저장 위치

카드뉴스 구성안은 `03_cardnews.md`에 저장한다. 실제 제작 파일은 콘텐츠 폴더의 `output/` 또는 `outputs/cardnews/`에 저장한다.

최종 운영 구조는 다음처럼 나눈다.

- 콘텐츠 폴더의 `output/cardnews/`: 최종 업로드용 카드 이미지와 README만 보관
- `outputs/cardnews/index.html`: 발행 콘텐츠 카드뉴스를 한 번에 보는 보관용 갤러리
- `outputs/cardnews/legacy/`: 이전 제작 원본, HTML/CSS/JS, 보조 이미지, 발행 여부가 불확실한 후보 보관
- `templates/cardnews/`: 재사용 가능한 제작 템플릿 보관

## 인스타그램 게시 문구

카드뉴스를 제작할 때는 별도 요청이 없어도 해당 콘텐츠의 `03_cardnews.md`에 인스타그램 게시 문구를 함께 기록한다.

- 기본 3안으로 작성한다.
- 각 안은 카드뉴스의 핵심 질문과 정서를 짧게 전달한다.
- 경험 중심형, 지식·개념 중심형, 질문·참여 유도형처럼 서로 다른 결을 사용한다.
- 긴 해설보다 인스타그램 캡션으로 바로 사용할 수 있는 간결한 문장으로 쓴다.
- 해시태그는 필요할 때만 5~10개 이내로 덧붙인다.

## PNG 렌더링

- 카드뉴스 HTML을 완성한 뒤 `tools/export-cardnews.mjs`로 각 카드를 1080 × 1350 PNG로 내보낸다.
- 템플릿의 카드 클래스가 바뀌더라도 내보내기 도구가 `card-item/card-shell`과 기존 `item/shell` 구조를 모두 인식하는지 확인한다.
- 최종 PNG는 콘텐츠 폴더의 `output/cardnews/exports/` 아래에 둔다.
- 표지 이미지 등 보조 자산은 제작 원본과 함께 `output/cardnews/images/`에 둔다.
- 내보낸 카드 수, 규격, 첫 장 이미지 삽입 여부, 텍스트 잘림 여부를 확인한 뒤 README에 상태를 기록한다.

콘텐츠 폴더의 `output/cardnews/` 아래에는 콘텐츠 이름을 반복하는 하위 폴더를 만들지 않는다. `card-01.png`, `card-02.png`, `README.md`처럼 바로 보이게 둔다.

콘텐츠 폴더에 HTML/CSS/JS 제작 원본과 보조 이미지를 반복 복사하지 않는다. 카드 장수는 콘텐츠마다 달라도 `exports/` 안의 최종 이미지 묶음과 갤러리 목록만 갱신하면 된다.

## 제작 스킬

한국어 타이포그래피 중심 카드뉴스 HTML을 제작할 때는 `typographic-cardnews` 스킬을 기본으로 사용한다.

- 재사용 템플릿 위치: `templates/cardnews/typographic-cardnews/`
- 이전 카드뉴스 이관 산출물 위치: `outputs/cardnews/legacy/`
- 최종본을 콘텐츠별로 정리할 때는 해당 콘텐츠 폴더의 `output/cardnews/` 바로 아래에 카드 이미지와 README만 둔다.
- 전체 열람용 보관 목록은 `outputs/cardnews/index.html`에 누적한다.
