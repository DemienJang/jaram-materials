# Idea Pipeline Guide

## 목적

블로그 아이디어를 발굴하고, 검토·작성·발행 상태를 추적하는 운영 기준이다.

## 원천자료와 작업자료

- `C:\Users\adona\OneDrive\My-wiki`는 읽기 전용 원천자료로 사용한다.
- 원천자료는 수정하지 않는다.
- 필요한 내용만 `contents/000-idea-pipeline/` 또는 개별 콘텐츠 폴더에 기록한다.
- 기존 원천자료의 최초 참고본은 `incoming/my-wiki-import/`에 보관한다.

## 아이디어 상태

아이디어는 다음 상태 중 하나로 관리한다.

- 아이디어
- 검토
- 기획
- 작성 중
- 발행 준비
- 발행 완료
- 보류
- 폐기

## 개별 콘텐츠 전환

아이디어가 실제 글로 발전하기로 결정되면 다음 순번의 `contents/NNN-short-topic/` 폴더를 만들고 `00_brief.md`부터 작성한다.

## 기록 원칙

- 아이디어마다 원천자료 위치를 기록한다.
- 개인 경험은 원천자료에 있는 내용만 사용한다.
- 발행 상태와 다음 작업을 함께 기록한다.
- 같은 주제의 중복 아이디어는 관련 콘텐츠를 연결하고 하나로 통합한다.
