# Posting Workflow

## 목적

게시 워크플로는 하나의 블로그 글이 여러 채널로 자연스럽게 확장되도록 순서와 상태를 관리한다.

블로그 글은 원천 콘텐츠다. 게시 운영은 블로그 본문을 먼저 완성하고, 그 글에서 스레드, 카드뉴스, 인스타그램, 교육자료, 타이틀 이미지를 파생시키는 방식으로 진행한다.

## 카테고리

기본 카테고리는 다음 흐름을 참고한다. 카테고리는 단순 분류가 아니라 글의 관점과 게시 흐름을 정하는 기준이다.

- 자라는 생각: 삶, 진로, 교육, 관계, 자기이해, 불안, 선택, 성장에 관한 글. 정보 전달보다 경험과 질문, 사유가 중요하다.
- 자라는 도구: 워크북, 질문지, 활동지, 코칭 도구, 교육 자료와 연결되는 글. 도구 소개 전에 왜 이 도구가 필요한지에 대한 문제의식이 먼저 나와야 한다.
- 자라는 시간: 독후감, 독서 에세이, 책을 통해 확장된 생각을 다룬다. 책 소개보다 책과 삶이 만나는 지점이 중요하다.
- 자라는 믿음: 설교, 묵상, 신앙의 질문을 다룬다. 신앙적 결론을 너무 빨리 내리지 않고, 본문 앞에서 자신이 먼저 마주한 질문을 보여준다.
- 자라는 흔적: 일상, 가족, 사역, 강의, 여행, 기록성 글. 가볍게 쓸 수 있지만 단순 일기에서 끝나지 않고 작은 장면에서 의미를 발견한다.

## 게시 순서

1. `01_blog.md` 블로그 본문을 완성한다.
2. 제목, 태그, 카테고리를 정리한다.
3. `05_image_prompt.md`로 타이틀 이미지를 준비한다.
4. `02_threads.md`로 스레드 버전을 만든다.
5. 필요하면 `03_cardnews.md`와 `04_edu_material.md`로 확장한다.
6. 게시 후 날짜, 채널, 링크, 후속 작업을 기록한다.

## 게시용 점검 항목

블로그 게시 전 다음을 확인한다.

- 제목이 글의 질문과 정서를 정확히 담고 있는가?
- 태그가 10개 이내이며 너무 넓지 않은가?
- 타이틀 이미지 방향이 글의 정서와 연결되는가?
- 스레드, 카드뉴스, 교육자료로 확장할 만한 핵심 장면이 있는가?
- 게시 후 기록할 날짜, 채널, 링크 위치가 정해졌는가?

## 파생 콘텐츠 흐름

하나의 글이 완성되면 다음 순서로 확장을 검토한다.

```text
블로그 본문 -> 제목/태그 -> 타이틀 이미지 -> 스레드 -> 카드뉴스 -> 교육자료
```

모든 글이 모든 형식으로 확장될 필요는 없다. 다만 확장하지 않는 경우에도 `00_brief.md`에 이유나 보류 상태를 남긴다.

## 상태 관리

각 콘텐츠 폴더에 현재 상태를 남긴다. 예: `초안`, `검토 필요`, `게시 완료`, `파생 콘텐츠 제작 중`, `보관`. 완료된 콘텐츠는 필요에 따라 `archive/`로 옮긴다.
