# Legacy Content Import Guide

## 목적

이 가이드는 통합 프로젝트를 만들기 전에 작성된 기존 콘텐츠를 현재 운영 구조 안으로 선별 이관하기 위한 기준이다.

핵심은 원본 폴더를 그대로 합치는 것이 아니라, 이후 참고와 이력 관리에 필요한 파일만 콘텐츠별 폴더로 정리하는 것이다.

## 기본 원칙

- 이전 자료는 먼저 임시 보관 위치에 둔다.
- 임시 보관 자료는 원본 확인용이며, 통합 운영의 정식 콘텐츠 폴더로 보지 않는다.
- 필요한 파일만 선별해 `contents/` 아래 콘텐츠별 폴더로 복사한다.
- 파일을 옮길 때는 원본 출처와 이관 판단을 `00_brief.md`에 기록한다.
- 개인 경험, 수업 장면, 대화, 설교, 코칭 기록 등은 원문에 있는 것만 사용한다.
- 중복 파일, 중간 저장본, 자동 생성 파일, 임시 이미지, 미사용 다운로드 파일은 정식 콘텐츠 폴더로 옮기지 않는다.

## 임시 보관 위치

기본 임시 보관 위치는 `incoming/`이다.

사용자가 외부 로컬 폴더 경로를 제공한 경우, 그 폴더를 읽기 전용 원본 보관소처럼 다루고 필요한 파일만 현재 프로젝트로 복사한다.

`incoming/`에 원본 파일을 잠시 넣을 경우에도, 원본 전체를 장기 보관 대상으로 보지 않는다. 정리 완료 후에는 필요한 경우 삭제하거나 `archive/`와 별도로 보관 여부를 결정한다.

## 이관 대상 판단

우선 이관할 파일:

- 완성 또는 거의 완성된 블로그 원고
- 콘텐츠의 주제, 배경, 핵심 질문이 담긴 메모
- 실제 경험, 수업, 상담, 대화, 독서, 설교, 강의 기록
- 이미 작성된 스레드, 카드뉴스 문안, 교육자료, 이미지 프롬프트
- 최종 산출물에 가까운 이미지, HTML, DOCX, PDF, 카드뉴스 파일

보통 이관하지 않을 파일:

- 시스템 파일, 압축 해제 흔적, 캐시, 다운로드 잔여물
- 이름만 다른 중복본
- 내용 차이가 없는 자동 백업본
- 출처나 용도를 알 수 없는 이미지
- 임시 실험 파일, 깨진 파일, 빈 파일

판단이 애매한 파일은 바로 버리지 말고, 해당 콘텐츠 폴더의 `00_brief.md`에 `검토 필요`로 기록한 뒤 원본 위치를 남긴다.

## 콘텐츠 폴더 변환 기준

이전 콘텐츠 1개는 현재 프로젝트의 콘텐츠 폴더 1개로 변환한다.

권장 폴더명:

```text
contents/YYYY-MM-short-topic/
```

작성일을 알 수 없으면 이관 월을 사용하고, `00_brief.md`에 원래 작성 시점을 `작성 시점 추정`으로 기록한다.

## 파일 매핑

이전 자료를 다음 기준으로 현재 구조에 맞춘다.

```text
주제/기획/메모/출처 기록      -> 00_brief.md
블로그 본문                  -> 01_blog.md
스레드 문안                  -> 02_threads.md
카드뉴스 구성안              -> 03_cardnews.md
교육자료 초안                -> 04_edu_material.md
타이틀 이미지 방향/프롬프트  -> 05_image_prompt.md
최종 산출 파일               -> output/
```

파일명을 바꾸더라도 원래 파일명과 원본 위치는 `00_brief.md`에 남긴다.

## `00_brief.md` 필수 기록

이전 콘텐츠를 이관할 때 `00_brief.md`에는 아래 항목을 반드시 포함한다.

```markdown
# 콘텐츠 브리프

## 이관 정보

- 이관일:
- 원본 위치:
- 원본 파일:
- 이관 판단:
- 누락/검토 필요:

## 콘텐츠 정보

- 주제:
- 카테고리:
- 핵심 질문:
- 주요 경험/장면:
- 참고 자료:
- 대상 독자:
- 현재 상태:
- 다음 작업:
```

## 작업 순서

1. 원본 폴더의 파일 목록을 먼저 확인한다.
2. 5개 콘텐츠로 나뉘는 기준을 찾는다.
3. 각 콘텐츠마다 `contents/YYYY-MM-short-topic/` 폴더를 만든다.
4. 먼저 `00_brief.md`를 작성한다.
5. 원본 블로그 글이 있으면 `01_blog.md`로 복사하거나 정리한다.
6. 파생 자료가 있으면 현재 표준 파일명으로 정리한다.
7. 최종 파일은 해당 콘텐츠의 `output/`에 둔다.
8. 옮기지 않은 중요한 파일이 있으면 `00_brief.md`의 `누락/검토 필요`에 남긴다.
9. 이관 완료 후 전체 목록과 다음 작업을 요약한다.

## 완료 기준

- 이전 콘텐츠 5개가 각각 `contents/` 아래 독립 폴더로 정리되어 있다.
- 각 폴더에 `00_brief.md`가 있다.
- 원본 출처와 이관 판단이 기록되어 있다.
- 필요 파일만 복사되어 있고, 불필요한 임시 파일은 정식 콘텐츠 폴더에 없다.
- 아직 판단이 필요한 자료는 버리지 않고 검토 항목으로 남겨져 있다.
