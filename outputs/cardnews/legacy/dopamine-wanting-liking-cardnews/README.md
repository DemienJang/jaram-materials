## 제작 메모

원문의 핵심 질문인 "정말 좋아한 걸까, 아니면 그냥 계속 원했던 걸까"를 중심으로 구성했다. 도파민 설명은 개념 카드 한 장으로 제한하고, 스마트폰 장면에서 시작해 원함과 좋아함의 구분, 신호, 진짜 필요, 작은 자유로 이어지는 흐름을 만들었다.
